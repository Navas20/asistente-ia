# Artenisa v5.0 Implementation Plan

**Goal:** Transform Artenisa from command bot to professional operations copilot.

**Architecture:** FastAPI backend + new modules (target_engine, memory_engine, playbooks, task_queue, report_generator, hacking/). Telegram bot rewritten with inline keyboards, wizards, voice/image. Plugin system. Security layer.

**Tech Stack:** Python 3.10+, FastAPI, python-telegram-bot v21+, SQLite, Ollama.

## File Structure

```
backend/
  target_engine.py      # Target Context Engine
  memory_engine.py      # 3-layer memory system
  hacking/
    __init__.py          # Package init
    network.py           # Port scanner, DNS, subdomain
    web.py               # SQLi, XSS, LFI, dirb
    crypto.py            # Hash id/crack, encoders
    payloads.py          # Reverse shell, webshell generators
    osint.py             # OSINT lookups (IP geo, cert transparency)
  playbooks.py           # Playbook engine (replaces workflows.py)
  task_queue.py          # Async task execution
  report_generator.py    # MD/HTML/JSON reports
  plugins/
    __init__.py          # Plugin loader
    plugin_base.py       # PluginBase abstract class
  security.py            # Rate limiting, audit log, roles
  telegram_bot.py        # Rewrite: keyboards, wizards, voice, images
  main.py                # Add v5 endpoints
  requirements.txt       # Add: pillow, jinja2, dnspython
```

### Task 1: Target Context Engine + Memory System

**Files:** Create `backend/target_engine.py`, `backend/memory_engine.py`

**target_engine.py:** `TargetEngine` class with `set_target(user_id, target, target_type)`, `get_target(user_id)`, `clear_target(user_id)`, `set_operation(user_id, operation)`, `get_context_summary(user_id)`. Persists to `data/target_state.json`.

**memory_engine.py:** `MemoryEngine` class with 3 layers:
- Layer 1: Recent messages (last 20-50) from existing messages table
- Layer 2: Operational context stored as JSON in `operation_context` table with `store_operational(conv_id, context)`, `get_operational(conv_id)`, `merge_operational(conv_id, updates)`
- Layer 3: Historical operations in `operation_history` table with `store_historical(target, operation, summary, findings_count)`, `get_history(target)`
- Smart summary: `needs_summary(conv_id, threshold=50)` checks message count modulo, `generate_summary(messages_text, llama_fn)` calls Ollama

---

### Task 2: Hacking Tools Module

**Files:** Create `backend/hacking/__init__.py`, `network.py`, `web.py`, `crypto.py`, `payloads.py`, `osint.py`

- **network.py:** `scan_ports(host, ports, timeout, max_workers)` multithreaded TCP connect scan, `banner_grab(host, port)`, `dns_enum(domain)` with dnspython, `subdomain_scan(domain, wordlist)` multithreaded, `whois_lookup(target)` via subprocess
- **web.py:** `detect_tech(url)` header/body fingerprinting, `check_sqli(url, param)` error-based + time-based detection, `check_xss(url, param)` reflected XSS, `check_lfi(url, param)` path traversal, `dir_bruteforce(url, wordlist)` multithreaded, `ssl_check(host, port)` cert inspection
- **crypto.py:** `hash_id(hash_str)` regex pattern matching for 14 hash types, `hash_crack(hash_str, wordlist)` dictionary cracking with hashlib, `encode_b64/decode_b64`, `generate_wordlist(base)`
- **payloads.py:** `reverse_shell(ip, port, shell_type)` bash/python/php/powershell/nc, `webshell(lang)` php/asp/aspx/jsp/py, `encode_payload(payload, method)` b64/hex/url/unicode
- **osint.py:** `ip_geo(ip)` via ip-api.com, `email_osint(email)` breach source references, `cert_transparency(domain)` via crt.sh

### Task 3: Playbook Engine

**Files:** Create `backend/playbooks.py`. Modify `backend/workflows.py` to delegate.

5 playbooks: recon_web, web_audit, osint_domain, password_audit, full_scan.
Each has steps array with id, label, tool function name.
`run_playbook(name, target, depth, hacking_module, target_engine, memory_engine, conv_id, progress_callback)` executes steps sequentially, stores operational memory after each step, stores historical on completion.

---

### Task 4: Async Task Queue

**File:** Create `backend/task_queue.py`

`TaskQueue(max_concurrent=3)` with thread-based worker loop. Tasks persisted to `data/tasks.json`. Methods: `submit(task_type, target, params)`, `get_status(task_id)`, `list_tasks(limit)`, `cancel(task_id)`, `update_progress(task_id, progress, step)`, `complete(task_id, result)`, `fail(task_id, error)`.

---

### Task 5: Security Controls

**File:** Create `backend/security.py`

- `AuditLog` class: creates `audit_log` table, `log(user_id, username, command, target, status, details)`, `get_recent(limit)`
- `RateLimiter` class: sliding window per key, `check(key, max_calls, window)` returns (allowed, remaining, reset_after)
- `get_role(user_id)` and `require_role(min_role)` decorator based on ALLOWED_USER_IDS / ADMIN_IDS env vars

### Task 6: Plugin Architecture

**Files:** Create `backend/plugins/__init__.py`, `backend/plugins/plugin_base.py`

`PluginBase` abstract class with name, version, description, commands, playbooks, on_load(), on_unload(), handle_command(), get_manifest().
`PluginManager(plugins_dir)` with discover(), get_plugin(), list_plugins(), handle_command().

### Task 7: Report Generator

**File:** Create `backend/report_generator.py`

`generate_report(target, data, fmt)` generates informed in MD (markdown with sections), HTML (styled table view), JSON (structured). Saves to `data/reports/`. Returns path, filename, size, mime, content.

### Task 8: Telegram Bot Rewrite

**File:** Modify `backend/telegram_bot.py`

Complete rewrite with:
- ReplyKeyboardMarkup main menu with 9 category buttons
- InlineKeyboardMarkup for recon type selection, depth selection, cancel
- CallbackQueryHandler for all button interactions
- Wizard state machine per user (user_wizards dict)
- Photo handler: upload via API, confirm receipt
- Voice handler: download, convert ogg->wav with ffmpeg, transcribe with vosk, respond

- /analizar command for OCR analysis of uploaded images
- /objetivo command to set target
- /voz toggle for TTS responses
